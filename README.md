---
## Notes

- The only network dependency is Google Fonts (Sora/Inter), which degrade gracefully to system
  fonts offline. Everything else is local.
- Animations respect `prefers-reduced-motion` and are disabled for users who opt out.
- All paths are **relative** (`./media/...`), so the site works at any GitHub Pages subpath
  without configuration.
- Media was extracted from the actual projects in `D:\DEV` — launch videos from Chromaflow,
  screenshots captured live at desktop (1440×900) and mobile (390×844) viewports, and the
  self-contained NovaPOS showroom pages.
